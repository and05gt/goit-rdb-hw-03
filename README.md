# Data Loading and SQL Basics. DQL Commands

## Homework Assignment Description

1. Write an SQL query that allows you to:

- select all columns (using the wildcard "\*") from the `products` table;
- select only the `name` and `phone` columns from the `shippers` table,\
  and verify that it executes correctly in MySQL Workbench.

2. Write an SQL query that finds the average, maximum, and minimum values of the `price` column in the `products` table, and verify that it executes correctly in MySQL Workbench.

3. Write an SQL query that selects unique values for the `category_id` and `price` columns in the `products` table.\
   Sort the results in descending order by the `price` value and select only 10 rows. Verify that the query executes correctly in MySQL Workbench.

4. Write an SQL query to find the number of products (rows) whose prices fall within the range of 20 to 100, and verify that it executes correctly in MySQL Workbench.

5. Write an SQL query to find the number of products (rows) and the average `price` for each supplier (`supplier_id`), and verify that it executes correctly in MySQL Workbench.
